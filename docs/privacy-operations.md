# 개인정보 운영 기준 — 2026-11-02

## 운영자가 확정한 기준

- 연결 이용자는 만 14세 이상이며 GitHub·Discord 및 거주 국가가 요구하는 더 높은 연령도 충족해야 한다. 보호자 동의를 받아 14세 미만에게 제공하는 서비스는 운영하지 않는다. 생년월일·신분증은 기본 가입 정보로 수집하지 않는다.
- 진단 로그와 관리자 작업 기록: 30일 기준. 자동 정리는 서비스 시작 및 일일 주기로 수행한다.
- 정상 종료된 업데이트 기록과 식별 가능한 자동 백업: 30일 이후 정리. 진행 중인 업데이트와 미해결 복구 자료는 삭제를 유예한다. 운영자가 주기적으로 실패 상태를 확인하고 복구를 완료하거나 더 이상 필요하지 않음을 검토해야 한다.
- 지원 문의 메일: 처리 완료 후 30일 이내 운영자가 직접 삭제한다. 봇은 메일함에 접속하거나 삭제하지 않는다.
- 수동 외부 백업은 서버 자동 정리 범위에 포함되지 않는다. 운영자가 동일 보관 기준으로 삭제하고 복원 시 이미 처리한 삭제 요청이 되살아나지 않도록 다시 반영한다.

## 삭제 요청을 받았을 때

1. support@teamhjd.com에서 본인 또는 적법한 대리인의 요청을 접수한다. 연결 관리자가 아니라도 본인 정보에 대해 요청할 수 있다. 신분증·비밀번호·토큰을 기본 확인 수단으로 요구하지 않는다.
2. 요청 종류, GitHub 항목 링크, 관련 Discord 서버나 메시지 등 최소한의 범위를 확인한다. 다른 사용자의 활성 연결 전체를 임의로 삭제하지 않는다.
3. 본인·대리 권한과 법정 보관 사유, 서비스 대기열·원본 GitHub·이미 전송된 Discord 기록의 처리 주체를 확인한다. 법령상 기간에 맞춰 처리하고 불가한 부분과 이유를 회신한다.
4. 대기열 재전송으로 삭제된 내용을 다시 전달하지 않도록 관련 전달을 먼저 제한한다. 전체 연결 해제와 개별 제3자 정보 삭제는 별개의 요청이다. 연결 해제의 자동 정리는 30일 후이며 즉시 개별 삭제 기능을 의미하지 않는다.
5. 자동 백업·외부 수동 백업·메일함까지 확인한다. 외부 GitHub·Discord가 독립적으로 보관한 내용은 해당 서비스 또는 서버 관리자의 별도 조치가 필요하다.

## 자동 정리 범위

`operational_retention.py`는 Receiver 로그의 인식 가능한 회전 파일, 관리자 감사 테이블, 정상 종료된 관리자 업데이트 작업, 이름이 일치하는 서비스 백업과 진단 작업, 완료 상태가 있는 CD 작업만 정리한다. 임의 폴더·파일, 인증 원본, 활성 이벤트 대기열, Caddy·Perforce는 건드리지 않는다. 심볼릭 링크·Windows junction·서비스 루트 외부 경로는 따라가지 않는다. CD의 독점 잠금이나 관리자 업데이트 진행 상태가 있으면 백업 정리를 유예한다.

Caddy·Cloudflare·GitHub·Discord의 자체 기록은 이 코드로 삭제하지 않는다. 각 서비스의 실제 로그 설정·보관 기간·처리 지역과 위탁/제공 관계는 운영자가 관리 콘솔과 계약 조건에서 확인해야 한다. 공개 정책은 미국 기반 제공자를 사용한다는 사실과 실제 모든 처리 지역은 같지 않음을 명시한다.

## 분석 도구와 동의

현재 앱에는 광고 SDK와 마케팅 이메일 발송이 없다. Cloudflare가 삽입한 분석 비콘은 확인한 공개 페이지의 CSP에서 차단됐다. Cloudflare 콘솔에서 Web Analytics/Browser Insights 설정을 확인하고, 사용하지 않을 기능은 비활성화한다. 이번 코드 변경은 콘솔 설정을 바꾸지 않는다. 분석을 활성화하거나 필수 아닌 추적을 추가하면 데이터 항목·목적·실제 기간을 다시 확인하고 정책과 필요한 동의 수단을 먼저 마련한다.

연결 화면의 약관 동의와 공개 범위 확인은 다른 저장소 참여자를 대신한 개인정보 제공 동의가 아니다. 조직 관리자는 저장소 참여자에게 필요한 고지와 적법한 전달 권한을 확보해야 한다. 개인정보 수집·국외 이전의 법적 근거와 위탁/제공 관계는 실제 계약·이용 형태에 맞춰 검토하며 체크박스 하나로 모든 요건을 충족했다고 보지 않는다.

## 결제 출시 전

현재는 무료 베타이며 결제 기능을 활성화하지 않는다. 최종 가격·세금·갱신·해지·환불·결제 대행사의 처리와 실제 사업자 표시사항을 확정한 다음 약관·구매 화면·개인정보 안내를 함께 갱신한다. 무료 이용자의 자동 유료 전환은 하지 않는다.

## 이미지 처리 라이브러리 보안 보완

실제 노트북의 `vendor-presence-v1/PIL`은 12.3.0으로 확인됐다. Pillow 공식 13.0.0 릴리스의 보안 수정을 적용한다. CD는 공식 PyPI Windows Python 3.12 x64 wheel의 URL·용량·SHA-256을 고정해 서비스 정지 전에 다운로드하고 PNG·GIF 읽기/쓰기 검사를 수행한다. `vendor-pillow-13`에만 격리 설치하며 기존 `vendor-presence-v1`을 덮어쓰지 않는다. 바이트 해시가 다른 기존 격리 폴더는 임의로 교체하지 않는다. 적용 실패 시 이번에 추가한 격리 폴더도 확인 후 원복한다. 이미지 축소는 13 이상에서 허용된 이미지 형식만 디코딩한다.
